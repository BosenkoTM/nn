


Тематика занятия — **Основы обнаружения объектов (Object Detection) с помощью нейросети YOLO**.

1. **Знакомство с инструментом.** Использование современной библиотеки `ultralytics` и предобученной модели YOLO для автоматического поиска людей и объектов на фотографиях.
2. **Оценка качества детекции.** Разбор базовых метрик машинного обучения (Матрица ошибок) на понятных примерах: 
   * **TP** (истинные срабатывания — объект найден верно);
   * **FP** (ложные срабатывания — модель ошиблась, "увидев" объект там, где его нет);
   * **FN** (пропуски — модель не заметила реальный объект).
3. **Настройка чувствительности.** Изучение того, как параметр порога уверенности (`conf`) влияет на результаты алгоритма (поиск баланса между ложными срабатываниями и пропущенными объектами).
